# مکعب روبیک هوشمند 🧩

یک اپ اندروید آفلاین که مکعب روبیک را با یک مدل کلاسیک **TF‑IDF + رگرسیون لجستیک** حل می‌کند.
نه LLM، نه GPU، نه شبکه عصبی.

**ایده:** هر حالت مکعب به یک جمله فارسی ترجمه می‌شود و مدل از روی همان جمله حرکت بعدی را انتخاب می‌کند.

```
مرحله لایه میانی. ... لبه هدف سبز-قرمز است که باید به جای جلو-چپ برود.
این لبه در لایه بالا، جای بالا-جلو است. ... لبه باید به سمت چپ برود.
→ مدل: «درج لبه از جلو به چپ»  (U' L' U L U F U' F')
```

## نتایج

| | |
|---|---|
| حل‌های کامل دیده‌شده توسط معلم | ۱۰۰۰ |
| جمله‌های فارسی یکتا | ۵٬۵۳۰ |
| برچسب‌ها (حرکت یا فرمول) | ۴۲ |
| دقت روی جمله‌هایی که مدل ندیده (آموزش روی ۷۰٪) | **۹۹٫۶٪** |
| حجم مدل | حدود ۲۶۰ کیلوبایت |
| حل کامل فقط با مدل، روی ۱۰۰۰ مکعب جدید | **۱۰۰۰ از ۱۰۰۰**، بدون هیچ اصلاح |
| میانگین حرکت تا حل | حدود ۱۷۰ |

## نصب

فایل [`release/RubiksCubeAgent.apk`](release/RubiksCubeAgent.apk) را روی گوشی (اندروید ۸ به بالا) نصب کنید
(باید «نصب از منابع ناشناس» را اجازه دهید). هر push هم در GitHub Actions یک APK تازه می‌سازد.

## امکانات اپ
- مکعب سه‌بعدی با انیمیشن، چرخاندن با انگشت
- نمایش جمله‌ای که مدل می‌خواند، تصمیم مدل و ۵ احتمال برتر
- حل خودکار یا گام‌به‌گام، بهم‌ریختن تصادفی، چرخاندن دستی وجه‌ها
- **وارد کردن رنگ‌های مکعب واقعی** (با بررسی حالت‌های غیرممکن) و دنبال کردن حرکت‌ها روی مکعب خودتان
- کاملاً آفلاین

## ساختار

| مسیر | کار |
|---|---|
| `web/cube.js` | موتور مکعب: حرکت‌ها، پیدا کردن قطعه‌ها، اعتبارسنجی |
| `web/policy.js` | «معلم»: روش لایه‌به‌لایه در ۷ مرحله که هر حالت را به جمله فارسی + برچسب تبدیل می‌کند |
| `web/model.js` | اجرای مدل TF‑IDF + رگرسیون لجستیک در جاوااسکریپت |
| `web/index.html`, `web/app.js` | رابط کاربری و نمایش سه‌بعدی (three.js) |
| `tools/gen_data.js` | ساختن داده آموزشی از حل‌های معلم |
| `tools/train.py` | آموزش با scikit-learn و خروجی گرفتن مدل |
| `tools/search.js` | پیدا کردن و بررسی فرمول‌ها با جستجو |
| `android/` | پروژه اندروید (WebView که فایل‌های `web/` را از assets اجرا می‌کند) |

## ساختن دوباره

```bash
node tools/gen_data.js 1000 > data/dataset.json
pip install scikit-learn
python3 tools/train.py data/dataset.json models/model.json web/model_data.js
cd android && ./gradlew assembleRelease
```

برای دیدن اپ در مرورگر کافی است `web/index.html` را باز کنید.

در اپ، اگر انتخاب مدل با معلم فرق کند، معلم آن را اصلاح می‌کند و شمارنده «اصلاح توسط معلم» یکی بالا می‌رود.
